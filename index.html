计算机图形学与 GIS 可视化 · 93 分

miniGL —— 自研软渲染二维 / 三维图形引擎与 GIS 可视化系统

C++ / Win32 · GDAL · 软件光栅化 · 纯 CPU 渲染（大三上课程项目）

演示视频（待添加）

从零实现、不依赖 OpenGL / DirectX / GPU 的“迷你 OpenGL”式图形引擎： 手写颜色帧缓冲与 Z-Buffer，逐像素完成全部光栅化；同时内置矢量图层管理与 2D 制图工具， 并借助 GDAL / OGR 读取真实 GIS 数据（Shapefile、GeoTIFF 影像、DEM 高程）， 实现图形学算法 + 空间数据 + 三维地形的统一可视化。

功能特性

  • 2D 矢量制图：点 / 折线 / 多边形 / 圆 / 椭圆绘制，图层管理、漫游缩放与鹰眼视图
  • 光栅算法齐全：Bresenham 直线、中点圆 / 椭圆、有序边表多边形扫描线填充
  • 编辑工具：拾取平移 / 缩放 / 旋转、镜像对称、Sutherland–Hodgman 矩形裁剪、油漆桶泛洪填充
  • 软件 3D 管线：MVP 变换、齐次裁剪、背面剔除、Z-Buffer 深度测试、重心坐标属性插值
  • 光照与纹理：Phong / Blinn-Phong 光照，20+ 种程序化纹理与自定义图片贴图
  • 图形实时切换：平面 / 长方体 / 球 / 棱锥 / 四面体 / 圆柱 / 圆锥一键切换
  • 3D 交互：虚拟跟踪球（Rodrigues 旋转）、线框 / 实体 / 顶点显示、投影方式切换
  • DEM 三维地形：GDAL 读 GeoTIFF 生成地形网格，Q / E 实时 LOD 抽稀
  • 地形表达：高程色带着色与正射影像贴图两种模式

开发路线（自底向上的模块化架构）

  1. 图形基础设施 —— 软帧缓冲（RGB / Alpha / Z-Buffer / 模板缓冲）、DIB 上屏、像素 / 网格双粒度绘制
  2. 2D 光栅原语库 —— Bresenham、中点圆 / 椭圆、有序边表扫描线填充，构成绘图内核
  3. 矢量数据与地图交互 —— Geometry 图元体系、图层 / 数据集、仿射视图变换、鹰眼
  4. 编辑与分析工具 —— 拾取、镜像、矩形裁剪、油漆桶填充 + 8 方向边界跟踪
  5. 空间数据导入 —— GDAL / OGR 读取 Shapefile、影像栅格、GeoTIFF DEM
  6. 三维软件渲染管线 —— 数学库（Vec / Matrix）、场景图、剔除、Z-Buffer、Phong、纹理、几何体切换、虚拟跟踪球、DEM / LOD

创新点

  • 零 GPU 依赖的“迷你 OpenGL”：自研软帧缓冲 + Z-Buffer，渲染管线与 OpenGL 固定管线逐段对应，教学与演示价值强；
  • 栅格—矢量一体化：油漆桶像素填充结果经 8 方向边界跟踪自动转回矢量多边形，可与平移 / 旋转 / 裁剪等矢量操作统一处理；
  • 三维图形实时切换 + 虚拟跟踪球：场景图重建与 Rodrigues 旋转叠加，交互手感接近商业软件；
  • 真实 DEM 三维地形：GeoTIFF 高程建模，实时 LOD 抽稀，高程色带 / 正射影像贴图双模式；
  • 20+ 种程序化纹理均由解析式与值噪声即时生成，无需任何外部贴图资源。

地图设计与电子地图学 · 92 分

夜间脉搏 Night Pulse —— 基于 VIIRS 夜间灯光的经济活力与恢复诊断地图

Vue3 / TypeScript / MapLibre GL / Three.js · FastAPI / SQLite · VIIRS 夜光遥感 （大三下课程项目）

演示视频（待添加）

若此处仍显示占位，请在 js/main.js 的 VIDEOS 配置中填写视频地址。

以 2019 – 2024 年中国 385 个地级市月度夜间灯光（VIIRS / NTL）数据为基础， 量化评估疫情等外部冲击对城市经济的影响程度、抵抗能力与恢复轨迹，并通过 前后端分离的交互式 Web 电子地图进行“全国 → 城市群 → 城市”多层级可视化诊断。

功能特性

  • 3D 引导页：Three.js 旋转地球 + 中国定位标记环，平滑过渡进入中国视角
  • 夜光影像：28 张 VIIRS 季度影像按地理坐标叠加，透明度可调
  • 时间轴播放：2019Q1–2024Q4 逐季度自动播放（0.5× / 1× / 1.5× / 2×）
  • 7 种专题图层：基础夜光 / 城市群协同评价 / 经济韧性类型 / 抵抗能力 / 后疫情恢复 / 疫情冲击 / 恢复稳定性
  • 城市诊断面板：4 项核心指标圆环 + 诊断结论文字
  • 夜间脉搏线：72 个月 VI 序列 SVG 面积图，标注冲击窗口、最低点与恢复达标点
  • 指标模型：Impact / Resistance / Recovery / Volatility / Loss_T 等 8 项恢复指标 + 韧性四象限分类
  • 城市群协同评价：21 个城市群综合评价排名与地图联动（熵权法校准）
  • 多维动态查询：按年份 / 区域 / 韧性类型 / 指标区间组合筛选，地图黄色高亮

指标口径（示意）

  • 活力指数 VI = 当月夜光均值 / 2019 年同月基线 —— 以“相对比值”消除城市规模与宏观波动的影响；
  • 恢复指标体系：冲击影响 Impact = 1 − Min(VI, 2020.01–04)，抵抗力 = 城市 VI / 全国 VI 均值，恢复程度 = Mean(VI − 1)，波动性 = 变异系数 CV 等；
  • 经济韧性四象限：按（高 / 低抵抗）×（快速 / 缓慢恢复）将城市分类诊断。

开发路线（数据处理 → 建库 → 服务 → 前端）

  1. 离线 ETL 流水线 —— 5 步脚本链：合并 2019–2024 月度 CSV 并清洗 → 计算同月基线 & VI → 计算 8 项恢复指标与韧性分类 → 融合地级市边界导出 Web GeoJSON / 时序 JSON（拓扑简化、质量报告）
  2. 数据建库 —— SQLite 5 张表（城市 / 边界 / 恢复指标 / 月度 VI / 季度影像元数据），约 2.7 万条月度记录自动入库
  3. 后端服务 —— FastAPI + SQLAlchemy：城市、恢复指标、时序、影像、动态查询、城市群评价六大路由模块
  4. 前端地图 —— Vue3 + MapLibre GL 专题图层与夜光影像叠加、时间轴播放、点击诊断、动态查询、城市群评价
  5. 模型校验 —— 城市群协同评价熵权法赋权 + P5–P95 鲁棒归一化，输出数据驱动校准报告

创新点

  • 夜光“相对化”思路：以 VI 比值刻画“冲击—恢复”轨迹，使不同规模城市可横向比较，夜间灯光成为城市经济韧性的“脉搏”指标；
  • 城市群协同评价三维度 + 熵权法客观校准：整体恢复水平、恢复覆盖程度、内部差异（区分度最高）由信息熵客观赋权，替代主观权重；
  • 多层电子地图表达：遥感影像、行政区矢量与 7 类指标专题叠加，分级设色、悬停气泡、点击联动的符号化叙事设计；
  • 数据质量工程：多编码兼容读取、安全除法、P5–P95 鲁棒归一化、800m 拓扑简化，保证大数据量前端渲染性能。

水文资料 OCR 识别与水利数据建库系统（智慧水文）

Python / Flask · PaddleOCR · DeepSeek 大模型 · SQLite · Leaflet / Cesium （大三下创新实践项目）

演示视频（待添加）

面向以纸质 / 扫描 PDF 形式存档的《水文年鉴》，实现 “扫描件 → 图像增强 → OCR → 结构化表格 → 水文业务记录 → 地理编码（空间点位）→ SQLite 建库 → 2D / 3D 地图可视化与分析” 的端到端智慧水利工具：把水位、流量、降水等长序列水文资料自动变成可检索、带坐标、可入库、 可溯源的数字产品。

功能特性

  • 图像预处理：中值滤波、倾斜校正、CLAHE 增强、锐化与自适应二值化，OCR 前后对比
  • 智能识别：单页 / 全部页 / 页码范围 / 框选区域定点 OCR，异步任务与进度反馈
  • 版面分析：自动检测页面表格 / 图片 / 图表区域，生成“表 x-x”式命名
  • 表格重构：按 y / x 几何坐标还原单元格，处理 rowspan / colspan 多层表头，跨页续表智能合并
  • 水文建模：结构化作成水位 / 流量 / 降水等业务记录，支持在线校对与增删行列编辑
  • 数据导出：JSON / Excel（双 Sheet）/ CSV / Markdown，历史结果可再导入
  • 地理编码：DeepSeek 辅助抽取站点 / 河名 / 流域；本地库 → 内置库 → 在线 API → AI 择优四级策略
  • SQLite 建库：水位流量等动态指标列自动入库，历史扫描结果一键批量入库
  • 检索与溯源：多条件组合检索，任意记录可定位回原文 PDF 页码影像
  • 2D / 3D 地图：Leaflet 专题图（比例符号 / 分级设色 / 柱状 / 洪水淹没模拟 / 制图导出）+ Cesium 三维（锥体 / 热力图 / 等值线 / 地形剖面 / 时序洪水演进仿真）

开发路线

  1. 采集与预处理层 —— PDF 按 DPI 渲染扫描（PyMuPDF）、图像增强（OpenCV）
  2. OCR 与版面层 —— PaddleOCR 识别；专用后台工作线程承载全部 GPU 推理，规避 Windows 下 Paddle CUDA 多线程死锁
  3. 结构化提取层 —— 表格几何重构、跨页续表合并、水位 / 流量 / 降水业务建模（dataclass）
  4. 地理信息层 —— DeepSeek 表型 / 站点 / 流域语义解析 + 四级地理编码，坐标自动回存站点库
  5. 分析应用层 —— 统计分析、图表、SQLite 记录库与检索溯源
  6. 可视化与部署层 —— 2D / 3D 双地图、洪水演进仿真；一键安装启动（模型预下载、启动脚本）

创新点

  • 端到端“扫描件 → 空间数据库”一体化闭环，远超普通文字识别工具的范畴；
  • 专用 OCR 工作线程：解决 PaddlePaddle 在 Flask 多线程下 CUDA 上下文不安全的死锁问题，属关键工程创新；
  • 大模型深度参与：DeepSeek 负责表型判断、站点 / 河流 / 流域抽取、地理编码候选择优，规则引擎兜底；
  • 基于版面几何的表格重构与跨页续表合并（列数一致 + 前两列匹配 + 表头相似度阈值 + 页间隔约束）；
  • 站名别名库 + 四级地理编码策略：离线优先兼顾准确与数据安全，命中即回存坐标、支持批量补全；
  • “地图点位 → 详情 → 原文”双向溯源与人工质检闭环（置信度分档、框选补识别、坐标批量修正）。
